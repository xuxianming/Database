# 现状文档集（Current）

描述产品**当前实际**的能力、关键行为与限制，并给出各项结论相对**基线**的验证信心。与 [PDR 目标文档集](../pdr/00-README.md) 平级、互相独立；本集不写任务日志 / 待办 / 计划中的能力。

## 基线

<本集基线：**由项目显式选定**的代码快照 / 发布版本。若尚无选定基线，先向用户确认，不要默认取 main 或最新 release。写具体 revision / release + 日期；单独会移动的分支名不足以定位快照。例：vX.Y.Z（2026-XX-XX，commit abc123）。>

<基线在本文件声明一次，各模块 / 主题文件默认继承，无需逐条重复举证。个别文件基于不同基线时（如某模块已随新基线前移），在该文件单独覆写并在下方索引注明。验证信心同理：默认口径在此说明，只有例外才逐条标注。>

## Current 维护

- 同步只跟随**选定基线**：只记录已包含在该基线内的变更；尚未进入基线的改动不写入。
- issue 收尾时检查变更是否已包含在选定基线：是则更新受影响的 Current 文件（只改事实，不插入指向 issue 的自链接或任务历史）；否则不更新，在 issue 记一条待同步项。
- 基线前移时刷新受影响的 Current 文件（无自动化 / 钩子，属评审动作）。
- 实际状态未变则不改动。

## 与 PDR 的关系

- PDR = 目标（`docs/pdr/`），本集 = 实际形态；两棵树各自可读、互不内嵌。
- 两边的模块 / FR 用链接关联（语义 / 导航 / 契约链接皆可），多对多，不强制逐文件对应。
- 需要指向某项决策时，用描述性短语 + 指向稳定 ADR 文件的普通 Markdown 链接（例：支持 [离线使用](../adr/0003-offline.md)）；不转述 ADR 理由，ADR 链接可选、不自动推断。
- 对照目标与实际得到的是**候选**任务，供用户挑选；差异不都是缺失功能（可能是漂移 / 质量 / 未验证 / 目标过时）。

## 新增模块 / 主题

- 在本目录按需新增 `<模块>.md` 或主题文件（不强制编号对齐 PDR）；
- 在上方索引与阅读顺序登记入口；基于不同基线的文件在此注明；
- 结论默认继承本文件基线；仅当该文件基线不同或验证信心有例外时单独说明。
